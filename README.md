# Ryan Fraser Personal Portfolio

This responsive personal portfolio presents my education, technical skills, professional experience, and completed academic projects.

## Live Website

https://ryanfraser2024-bit.github.io/personal-portfolio/

## Website Sections

* Home: Introduction and GitHub access
* About: Education, experience, and technical skills
* Projects: Three featured technical projects
* Resume: Options to view and download my updated resume
* QR Code: Direct access to the live portfolio
* Contact: Form that creates a pre-addressed email

## Featured Projects

### Credit Card Payment Verification System

A web-based application that verifies credit card payment information before processing. The system checks required fields, card-number formatting, expiration dates, and security-code entries while providing clear verification messages. This project demonstrates form validation and secure payment-processing concepts using HTML, CSS, and JavaScript.

### Wireshark Packet Inspection

A network-security project involving the capture and analysis of DNS, HTTP, HTTPS, TCP, and UDP traffic. The project focused on identifying network protocols, analyzing traffic patterns, and detecting possible security concerns.

### Windows Server Administration and Hyper-V

A hands-on lab series involving Windows Server 2022, Hyper-V, virtual machines, Active Directory tools, file-sharing permissions, and Group Policy.

## Chatbot Implementation

The chatbot was created with JavaScript. It converts questions to lowercase and uses keyword matching to answer frequently asked questions about my education, skills, experience, resume, and technical projects, including the Credit Card Payment Verification System.

Chatbot messages are displayed using the JavaScript `textContent` property.
